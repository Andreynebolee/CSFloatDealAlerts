# CSFloat Deal Alerts

Сканер новых листингов CSFloat с алертами и автопокупкой. Работает локально,
ключ хранится на машине пользователя.

![Лента алертов](docs/alerts.png)

По каждой находке видно цену, скидку, абсолютную выгоду, референсную цену
и её источник.

## Установка

Сборки под Windows x64 — в [Releases](../../releases):

| Файл | |
|---|---|
| `...-portable.exe` | запуск без установки |
| `...Setup...exe` | установщик, ярлыки, автозапуск |

Подписи кода нет, поэтому SmartScreen при первом запуске покажет
«Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».

Дальше: «Настройки» → «Подключение» → API-ключ (csfloat.com → Profile →
Developer → New Key) → «Запустить».

## Фильтры

| Параметр | Смысл | По умолчанию |
|---|---|---|
| Цена | диапазон в USD | 1–200 |
| Скидка | минимум к референсной цене | 8% |
| Выгода | минимум в USD, 0 = выкл | 0 |
| Возраст листинга | максимум, минут | 1 |
| Трейды продавца | минимум, 0 = выкл | 0 |
| Ликвидность | продаж в сутки, 0 = выкл | 0 |
| Премия за float | максимум к базе, 0 = выкл | 10% |
| Строгость по наклейкам | множитель к справедливой надбавке | 1.0 |
| Типы предметов | 10 категорий | оружие |
| Акцент | следить за одним `market_hash_name` | — |
| Пауза опроса | между запросами к `/listings` | 8 с |

Пять встроенных пресетов: дешёвые флипы, ликвидное, ножи и перчатки,
наклейки, широкий поиск. Свои наборы сохраняются рядом.

Кнопка «Проверить» прогоняет текущую форму по истории листингов за час и
показывает, сколько сделок прошло бы и какой фильтр отсеял больше всего.
Каждый листинг судится по его возрасту на момент появления, иначе фильтр
свежести отбросил бы всю выборку.

## Референсная цена

Приходит вместе с листингом, по убыванию приоритета:

1. `reference.predicted_price` — оценка CSFloat с учётом float
2. `reference.base_price`
3. `item.scm.price` — Steam

Других источников цен приложение не использует и никаких платных ключей
не требует: хватает ключа CSFloat.

## Автопокупка

Выключена по умолчанию. Два режима:

**Выкуп лота** — `POST /listings/buy`, покупает именно тот предмет из алерта.
Эндпоинт недокументированный: работает, но может быть закрыт без
предупреждения. Документированной замены нет.

**Buy order** — `POST /buy-orders`, заявка «куплю такое за столько»,
срабатывает на следующем подходящем лоте. Документирован, но лот из алерта
не выкупает; то же самое доступно руками на сайте.

Ограничители в `app/main/autobuy.ts`: потолок на покупку, суточный лимит
с обнулением в полночь, подтверждение перед каждой покупкой, блокировка
повтора по предмету на 30 минут, потолок не выше максимальной цены поиска.
Покупки выполняются строго последовательно — иначе параллельные списания
читают один и тот же остаток лимита.

Выкупленный лот пишется в журнал сразу. Buy order — нет: неизвестно,
исполнится ли он. Активные ордера и их снятие — на вкладке «Ордера»,
список тянется с CSFloat.

## Уведомления

Системные уведомления Windows (клик открывает лот) и по желанию дубль
в Telegram: токен бота от @BotFather и chat id вводятся в «Настройки →
Уведомления», кнопка «Отправить тест» проверяет связь. Токен хранится в
`settings.json` открытым текстом — заводите для этого отдельного бота.
Карточки в приложении показывают картинку предмета, износ, float со шкалой,
скидку и выгоду; ленту можно отсортировать по времени, скидке или выгоде.

## Журнал

Покупки, продажи, P&L, экспорт в CSV. Прибыль считается как выручка минус
себестоимость проданного. Цена продажи вводится как полученная на руки,
после комиссии площадки.

## Разработка

```bash
npm install && npm start
```

```bash
npm run check      # проверки логики отбора, лимитов и P&L
npm run dist       # сборка установщика и portable
npm run screenshot # скриншоты интерфейса на демо-данных
```

Прогон движка без окна: `CSFLOAT_API_KEY=... npm run dev:engine`

```
app/engine/    без зависимости от Electron
  types.ts       модель листинга и сделки
  settings.ts    параметры поиска и валидация
  presets.ts     готовые наборы
  appraisal.ts   референсная цена, премия за float, наклейки
  filter.ts      чистая функция отбора
  feed.ts        опрос /listings, дедуп, backoff на 429
  orders.ts      выкуп лота и buy orders
  history.ts     постраничная выгрузка для dry-run
  dryrun.ts      прогон по истории и разбор отсева
  index.ts       DealEngine на событиях

app/main/      Electron
  engine-host.ts  движок и лента находок
  journal.ts      сделки, P&L, CSV
  autobuy.ts      лимиты автопокупки
  links.ts        внешние ссылки (поддержка проекта)
  secrets.ts      ключ через safeStorage
  preload.ts      contextBridge

app/renderer/  «Алерты», «Журнал», «Ордера», «Настройки»
```

`contextIsolation` и `sandbox` включены, Node в рендерер не пробрасывается,
обмен только через `window.api`.

## Данные

`%APPDATA%\csfloat-deal-alerts\`

| Файл | |
|---|---|
| `settings.json` | параметры поиска |
| `prefs.json` | настройки приложения |
| `presets.json` | свои пресеты |
| `deals.jsonl` | лента находок |
| `journal.json` | сделки |
| `autobuy.json` | суточный расход и ордера |
| `secrets.bin` | ключ, зашифрован через DPAPI |

При удалении приложения не стираются. Все файлы пишутся через временный файл
и переименование; если файл всё же оказался повреждён, приложение кладёт его
копию рядом (`*.corrupt-<дата>`), а не затирает молча.

Автозапуск «вместе с Windows» работает только у установленной версии: portable
каждый раз распаковывается во временную папку.

## Лимиты API

Пауза опроса 8 секунд по умолчанию. Ниже 5 секунд один домашний IP с одним
ключом упирается в 429. При 429 движок уходит в экспоненциальный backoff,
остаток квоты виден в шапке.
